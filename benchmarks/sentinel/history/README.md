# Histórico oficial da bancada Sentinel

Cada JSON registra uma rodada oficial concluída da bancada e identifica a revisão do Sentinel, motor, perfil, fixture e verificador. Os resultados são cumulativos por caso, sem selecionar a melhor repetição. As rodadas diagnósticas, os logs brutos, os prompts e a evidência interna não fazem parte deste histórico.

O tempo da rodada mede o tempo de parede, não a soma dos casos paralelos. A sobreposição mede janelas entre o aceite e a conclusão observados pelo cliente, não tempo computacional do provedor.

Os totais usam exclusivamente tokens reportados. Cache é um subconjunto da entrada; entrada nova é entrada menos cache. Raciocínio é um subconjunto da saída. Os contadores de relatórios faltantes ou parciais se referem aos campos observados. Respostas atribuídas são deduplicadas; ausência de lacunas nesses campos não descarta uso não reportado pelo provedor. Estes dados não representam custo de faturamento.
